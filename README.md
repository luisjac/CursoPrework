# Ukelele

Entrenadores interactivos de ukelele (acordes, letra y guía de ritmo).

Sitio: https://luisjac.github.io/ukelele/

## Agregar una canción

1. Copia `love-me-tender.html` con el nombre de la nueva canción.
2. Cambia `CHORDS` y `SONG_MEASURES`.
3. Añade un `<li>` con el enlace en `index.html`.

Cada push a `master` publica el sitio automáticamente en GitHub Pages.
